**SELVA KORPI**
Is a fictional language from a chilean kids show from early 2000's named 'Zoolo TV'.

The 'language' works more like a code cipher, where every letter on every word of the message can be:

1) Left the same, if the letter isn't contained on ['SELVA'] nor ['KORPI']
2) Exchanged for it's relative if it's contained either on ['SELVA'] or ['KORPI']
3) Spaces and symbols remain the same.

**Example Cases**

1) The letter 'A' is the 5th letter in ['SELVA'], so every 'A' should be replaced for the 5th letter in ['KORPI'], wich is 'I' 
2) The letter 'R' is the 3rd letter in ['KORPI'], so every 'R' should be replaced for the 3rd letter in ['SELVA'], wich is 'L'
3) The letter 'W' isn't contained in ['SELVA'] nor ['KORPI'], so it should NOT be replaced.


**Practical case**

Translate 'Hello world!' to SELVA KORPI.

H -> H **Not contained, left the same**
e -> o
l -> r
l -> r
o -> e

w -> w **Not contained, left the same**
o -> e
r -> l
l -> r
d -> d
